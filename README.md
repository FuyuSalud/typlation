# Typlation

Windows向け翻訳キーボードの試用版です。入力欄に書いた日本語をDeepLで翻訳し、その場で置き換えます。送信は自動で行わず、訳を確認してから自分でEnterを押します。

## 機能と制限
- 日本語から選んだ言語へ翻訳。1回の入力は2000文字までです。
- 翻訳先の選択、一時停止、各操作のショートカット編集に対応します。
- 「DeepLの最新対応言語を取得」でAPIが返す利用可能な翻訳先を取得します。初期一覧は候補であり、すべての言語の利用を保証しません。
- 言語・言語一覧・ショートカットは保存されます。
- 入力欄全体をCtrl+A/Cで取得し、翻訳後にCtrl+Vで置き換えます。コピー・貼り付けに対応する入力欄が必要です。
- 翻訳中に入力文や入力先が変わった場合は置き換えを中止しますが、入力欄の識別にはアプリごとの限界があります。
- 元のクリップボードのプレーンテキストは可能な場合に復元します。画像、ファイル、書式付きデータは復元できません。
- Discord、VALORANTなどのゲームやチャットアプリでの動作は未確認です。対応やアンチチートとの互換性は保証しません。入力がブロックされる場合の回避機能はありません。

## インストール

配布用ZIPはビルド済みです。初回リリースの公開準備中です。

1. [Releases](https://github.com/FuyuSalud/typlation/releases)の添付ファイル Translation_Keyboard_NoPython.zip をダウンロードし、ZIP全体を展開します。
2. 旧版とTyplationを終了して、展開先の install.bat を実行します。
3. デスクトップまたはスタートメニューの「Typlation」から起動します。

Pythonのインストールは不要です。インストーラーはinstall.batとPowerShellで、setup.exe形式ではありません。管理者として実行せず、利用するWindowsユーザーで実行してください。インストール先は %LOCALAPPDATA%\Programs\Typlation です。自動起動やWindowsの「インストールされているアプリ」への登録は行いません。

インストールせず試す場合は app\Typlation.exe を開きます。exeだけを移動せず、_internalフォルダーも一緒に保持してください。署名のない試用版です。

## DeepL APIキーと料金
DeepL APIのアカウントとインターネット接続が必要です。通常の翻訳サービスの契約だけでAPIが利用できるとは限りません。[DeepLの開発者向けページ](https://www.deepl.com/en/developers)で利用プランを確認し、[アカウントのキー管理画面](https://www.deepl.com/en/your-account/keys)でAPIキーを取得してください。

Typlation内にアプリ利用料の請求機能はありません。DeepL APIの料金、無料枠、新規受付状況はプラン・地域・時期によって変わります。[DeepL公式のAPIプラン説明](https://support.deepl.com/hc/ja/articles/360021200939)と契約画面で最新の条件を確認してください。Typlationには料金表示や利用上限を設定する機能がなく、失敗・再試行もAPI側の課金対象になる場合があります。

「APIキー・使い方」タブにキーを入力し、「APIキーを保存・更新」を押します。保存時に有効性や利用枠は確認しません。キーは現在のWindowsユーザーの資格情報マネージャーに保存し、次回起動時に読み込みます。変更は新しいキーを保存、削除は「保存したキーを削除」です。APIキーをIssuesやスクリーンショットに載せないでください。

## 使い方と初期ショートカット
1. まずメモ帳で短文を試してください。Typlationを起動したまま、対象の入力欄をクリックします。
2. 日本語を入力してIMEの変換を確定します。
3. 翻訳先を選び、翻訳キーを押してキーを離します。
4. 翻訳中は入力、送信、入力欄の切り替えをせず待ちます。
5. 置き換わった訳を確認し、必要に応じて編集してから送信します。

| 操作 | 初期キー |
| --- | --- |
| 翻訳 | Ctrl+Alt+T |
| 一時停止・再開 | Ctrl+Alt+P |
| 英語へ切り替え | Ctrl+Alt+1 |
| 中国語（簡体字）へ切り替え | Ctrl+Alt+2 |
| スペイン語へ切り替え | Ctrl+Alt+3 |

終了はウィンドウの×です。

## ショートカット編集
「ショートカット設定」で行を選び、Ctrl+Shift+EやF8などを入力し、「行に反映」→「設定を保存して適用」を押します。Ctrl、Alt、Shift、Winと、英数字またはF1〜F24を使えます。空欄は割り当てなしですが、翻訳キーは必須です。文字・数字だけのキーや、同時に反応する重複した組み合わせは使えません。他のアプリとの競合は検出できません。「初期値に戻す」→「設定を保存して適用」で初期設定を保存します。

## DeepLへの文章送信
翻訳キーを押すと、対象入力欄の全文をAPIキーによる認証とともにHTTPSでDeepLへ送信します。日本語を翻訳元として指定します。対応言語の取得時にもDeepLへ認証付きリクエストを送ります。常時入力文を記録・送信する機能や、翻訳履歴の保存機能はありません。個人情報や機密情報を含む文章は、利用するDeepLプランの規約・データ取扱いを確認したうえで使用してください。

## 設定の引き継ぎ
旧版と同じ保存先を使うため、同じWindowsユーザーの保存済みAPIキー・言語・ショートカットは引き続き利用できます。APIキーは設定ファイルや配布ZIPに含めません。

## アンインストール
Typlationを終了し、スタートメニューのTyplationフォルダー内の「Uninstall」を実行してYESを入力します。アプリとショートカットを削除しますが、APIキーと設定は保持します。

APIキーも消す場合は、削除前にアプリの「保存したキーを削除」を押します。個人用設定の削除は、アプリ終了後に保存先を確認して行ってください。この設定と資格情報は旧版と共有しているため、削除すると旧版からも使えなくなります。ポータブル利用では展開先フォルダーを削除します。旧版のアプリ本体は旧版のアンインストーラーで別途削除してください。
